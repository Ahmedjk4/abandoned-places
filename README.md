# Abandoned Places

A website showing abandoned places worldwide, and historical photographs for them with documenting their original dates and photographers.


The website contains 18 places from different countries, including Japan, Namibia, France, Spain, Belgium, Chile, Taiwan, Portugal, Germany, United Kingdom and Argentina, and 72 photographs.

The website has 4 pages, the home page, the archive containing all the places, the stories page, and about page.

The prompt given to Codex to build it: 
```
Identify what generic UI features AI would usually include (for example, color gradient (purple to blue), nested cards, colored backdrops with grey text and a hero section with two buttons). Then, exclude all of these.

Please also use DESIGN.md within the %userprofile% folder. Ensure that it uses the same colors, fonts and UI features as identified in DESIGN.md.

The site is called Abandoned Places. It will be a photographic library for deserted places, including: Abandoned hospitals, Forgotten amusement parks, Empty factories, Old railway stations, Abandoned hotels, Deserted villages, Forgotten military structures. Include pages like the home one for sure, archive page with each place location details, story of each place, and about page for the whole website.
```

- The DESIGN.md used to guide Codex was downloaded from [GetDesign Dell 1996](https://getdesign.md/dell-1996/design-md).
